# .github

Organization-level defaults for [The Harness Lab](https://github.com/THE-HARNESS-LAB).

| Path | Purpose |
|---|---|
| `profile/README.md` | The page shown on the organization's public profile |
| `profile/assets/` | Brand artwork used by that page |

## Brand assets

| File | Use |
|---|---|
| `harness-lab-badge.png` | Circular badge — the primary mark. Carries its own dark disc, so it renders correctly on light and dark backgrounds. |
| `harness-lab-avatar-512.png` | 512×512 source for the GitHub organization avatar (upload via Settings → Profile; GitHub's API cannot set it). |
| `harness-lab-lockup-stacked.png` | Stacked badge-over-wordmark lockup. |
| `titledesk-agent-logo.png` | Product mark for TitleDesk Agent. |

**Use the badge, not a transparent wordmark, anywhere the background is unknown.**
The cream-on-transparent lockups disappear against GitHub's light theme; the
badge and the composited lockups do not.
