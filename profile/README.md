## Engineering Principles

- **Primary-source grounded.** Every figure in a delivered artifact traces directly back to the recorded page or live source that produced it.
- **Exact domain math.** Mineral fractions and financial ledgers run in exact rational or integer minor-unit arithmetic — never raw floating point.
- **Harnesses own authority.** Models propose inside bounded sandboxes; deterministic code enforces policy, budgets, holdout verification, and human approval gates.
- **Full client ownership.** Client engagements ship in customer-owned repositories with reproducible setup, automated smoke tests, and operator runbooks.
